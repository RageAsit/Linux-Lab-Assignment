# Linux Lab Assignment

## Overview

This repository contains my solutions for the Linux Lab Assignment. Each question is organized in a separate folder and includes the required source code, scripts, documentation, and screenshots demonstrating the implementation.

## Repository Structure

```

│
```

## Questions Covered

### Question 1
- File backup automation using a Bash script.
- Duplicate file detection using checksums.
- Backup report and error logging.

### Question 2
- Linux process management using C.
- Demonstration of `fork()`, `waitpid()`, `kill()`, and process synchronization.

### Question 3
- File handling using Linux system calls.
- Demonstration of `open()`, `read()`, `write()`, `lseek()`, and `close()`.

### Question 4
- Linux log monitoring using shell commands.
- Use of `tail`, `grep`, pipes, redirection, and `/dev/null`.

### Question 5
- Evaluation of Vim (`vi`) recovery mechanisms.
- Discussion of swap files, undo history, registers, backup files, and auto-recovery.
